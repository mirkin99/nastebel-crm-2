# NASTEBEL CRM

CRM на GitHub Pages с серверным API в Supabase.

## Обновление 18.10.2026

- Исправлена неоднозначная SQL-переменная при изменении закупок. Ошибки API возвращаются текстом, а формы очищаются только после подтверждённого сохранения.
- Новый клиент создаётся из заказа без потери заполненных полей.
- Для пучков и упаковок доступен процентный учёт: 100% = одно целое. При закупке вводится число целых пучков и цена пучка; в заказе — использованная доля. Себестоимость рассчитывается по средневзвешенной стоимости позиции.
- Существующие позиции переводятся в проценты через «Изменить». База пересчёта задаёт число прежних единиц в 100%. Количества и стоимость единицы в остатках, закупках, резервах и списаниях пересчитываются одновременно; суммы сохраняются.
- Стоимость склада раскрывает свежие цветы, долговечные материалы и списания за выбранный период. Списания показаны отдельно от текущего склада.
- Добавлены обновление данных и защита от повторного нажатия кнопки сохранения.

## Проверки

`tests/database.sql` и `tests/crud.sql` проверяют расчёты и операции в транзакции с ROLLBACK. Запускать в SQL Editor Supabase. Созданные тестовые записи не сохраняются, значения последовательностей могут увеличиваться.

Браузерные проверки выполнены на широком экране и в окне 390 px: создание клиента из заказа, сохранение полей после ошибки, процентная закупка, редактирование позиции, раскрытие стоимости склада. Это проверка адаптивного интерфейса в Chromium; отдельные Safari/iOS и Android устройства не тестировались.

`supabase/percentage-inventory.sql` — применённое обновление схемы и функций. Авторизация и обработка ошибок серверного API обновлены в Edge Function `nastebel-crm-api`. Секреты и параметры доступа в репозитории не хранятся.
